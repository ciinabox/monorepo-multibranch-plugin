One repository, with a multibranch pipeline for each Jenkinsfile in it. Every branch of the repository is searched, so a Jenkinsfile added on a feature branch or in a pull request creates its project there. Each project is named after the directory that holds its Jenkinsfile, such as services/api; one at the top of the repository is (root).

Use it with the Monorepo: a pipeline per nested Jenkinsfile project factory, and the Monorepo: build when watched paths change build strategy so that a project builds only when something it watches changes.
